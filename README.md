
# Simple Interest Calculator

This project is a simple interest calculator.

## Description

The Simple Interest Calculator calculates simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- Principal amount
- Rate of interest
- Time period

## Output

The calculator displays the calculated simple interest.

## Project Purpose

The purpose of this project is to demonstrate the use of Git and GitHub while developing a simple Bash-based calculator.
